# ABC/XYZ анализ ассортимента

Интерактивный дашборд на Streamlit для классификации товарного ассортимента по вкладу в выручку (ABC) и стабильности спроса (XYZ). Подходит для маркетплейсов: загружаешь выгрузку продаж и получаешь матрицу сегментов с рекомендациями по управлению запасами.

## Что внутри

| Файл | Назначение |
|---|---|
| `app.py` | дашборд Streamlit |
| `abc_xyz.py` | расчёт ABC и XYZ, также запускается из командной строки |
| `generate_demo_data.py` | генератор демо-датасета в формате входных данных |
| `data/sales.csv` | демо-датасет: 150 артикулов тканей и фурнитуры за 12 месяцев |
| `requirements.txt` | зависимости |

## Методика

**ABC** считается по выручке. Артикулы сортируются по убыванию выручки, считается накопленная доля. Класс A закрывает первые 80% выручки, B следующие 15%, C оставшиеся 5%. Границы настраиваются.

**XYZ** считается по коэффициенту вариации спроса: `CV = стандартное отклонение / среднее` по периодам (неделя или месяц). Периоды без продаж учитываются как ноль, неполные крайние периоды отбрасываются.

| Класс | Коэффициент вариации (по умолчанию) | Характер спроса |
|---|---|---|
| X | до 0.25 | стабильный |
| Y | 0.25 - 0.5 | с колебаниями |
| Z | больше 0.5 | непредсказуемый |

Пересечение даёт 9 сегментов (AX, AY, ... CZ). Для каждого в дашборде есть рекомендация: тип пополнения, величина страхового запаса, кандидаты на вывод из ассортимента.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск дашборда

```bash
streamlit run app.py
```

В боковой панели можно загрузить свой CSV, выбрать период и категории, шаг для XYZ (неделя или месяц) и подвигать границы классов. Вкладки:

- **Матрица**: число артикулов и доля выручки по сегментам, таблица рекомендаций.
- **Парето**: выручка по артикулам с накопленной долей и раскраской по классам.
- **Спрос**: выручка против коэффициента вариации, динамика выручки по классам.
- **Артикулы**: полная таблица с фильтром по сегментам и выгрузкой в CSV.

## Запуск из командной строки

```bash
python abc_xyz.py --input data/sales.csv --freq M --out abc_xyz_result.csv
```

Параметры: `--freq` (`W` или `M`), `--abc-a`, `--abc-b`, `--xyz-x`, `--xyz-y`.

## Формат входных данных

CSV, одна строка на артикул за день:

| Колонка | Описание |
|---|---|
| `date` | дата продажи |
| `article` | артикул |
| `qty` | количество (метры или штуки) |
| `revenue` | выручка |
| `category` | категория, необязательно |

Для устойчивого XYZ нужна история минимум 8-12 недель или 6-12 месяцев.

## Свой датасет

Демо-данные можно перегенерировать с другими параметрами:

```bash
python generate_demo_data.py --articles 300 --days 365 --seed 1
```

## Ограничения

- Новые артикулы с короткой историей получают завышенный коэффициент вариации и попадают в Z.
- Сезонный спрос тоже даёт высокую вариацию: его стоит разбирать отдельно.
- XYZ считается по количеству, ABC по выручке.
